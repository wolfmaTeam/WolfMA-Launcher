# WolfMA Launcher 

**WolfMA Launcher** is a Windows desktop application designed to organize, manage, and launch PC games from one convenient interface.

## Features

* Organize installed PC games in one library.
* Launch games directly from WolfMA Launcher.
* Detect and manage local game executables.
* Track local gameplay time.
* Display game covers and artwork.
* Support for multiple game platforms.
* Customizable interface and application settings.
* Local storage of launcher preferences and game information.

## Privacy

WolfMA Launcher does not require user registration and does not intentionally collect personal information.

Application settings, game-library information, and playtime statistics are stored locally on the user's computer.
